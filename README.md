# Dotnet Web API Core 8

A comprehensive project demonstrating the implementation of a Web API using ASP.NET Core 8. This project serves as a tutorial for building modern RESTful APIs with .NET.

---

## Features

- Implementation of CRUD operations
- Entity Framework Core integration
- Dependency injection
- Exception handling
- JWT-based authentication and authorization
- OpenAPI/Swagger integration for API documentation
- Repository pattern for better maintainability
- Comprehensive logging with Microsoft.Extensions.Logging

---

## Prerequisites

Before running this project, ensure you have the following installed:

- .NET SDK 8.0 or later
- Visual Studio 2022 or Visual Studio Code
- SQL Server (or any supported database)
